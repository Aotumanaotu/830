## 5. 核心知识提要

### 5.1 算法、数据结构和复杂度

算法是求解问题的有限步骤；要明确输入、输出、每步含义和终止条件。逻辑结构描述元素之间的关系，存储结构描述这些关系在内存中的表示。线性关系可以用数组，也可以用链表实现。

时间复杂度描述基本操作次数随输入规模增长的量级，不直接等于运行秒数。常见量级：O(1)、O(log n)、O(n)、O(n log n)、O(n²)。精确同阶增长常用 Θ；考研解题通常用 O 给出紧的数量级。

- 连续两段循环相加，数量级取主导项。
- 循环嵌套不一定是 O(n²)，要看内层实际次数。
- `1+2+...+n=n(n+1)/2`，同阶为 n²。
- 每次把规模减半或翻倍，通常出现 log₂n。
- 递归空间包括调用栈；不能只数函数里几个变量。
- 分清最好、平均和最坏情况，平均情况需要相应输入假设。

### 5.2 C 的类型、表达式与输入输出

- `int` 是整数，`float/double` 表示浮点数，`char` 是字符类型。类型长度与表示范围需遵循题设和实现，不能把所有平台都固定为相同字节数。
- `5/2` 得 2；`5/2.0` 得 2.5。`double x=5/2;` 先做整数除法，再转换为浮点数，结果为 2.0。
- `=` 是赋值，`==` 是比较；`%` 用于整数余数。
- `&&`、`||` 有短路求值，逻辑结果为 0 或 1；`!` 表示逻辑非。
- 优先级决定结合方式，不保证所有子表达式求值顺序。不要为 `i++ + ++i` 之类具有未定义行为的表达式编造固定答案。
- 逗号运算符先求左操作数，再求右操作数，整个表达式的值与类型来自右操作数；函数实参的逗号分隔符不是逗号运算符。
- `printf("%d", x)` 输出 int；`printf("%.2f", d)` 输出两位小数。`scanf("%d", &x)` 接收 int，`scanf("%lf", &d)` 接收 double，float 使用 `%f`。
- `scanf` 返回成功赋值的项数，应据此检查输入。字符输入可能读到换行符；`" %c"` 中前导空白的含义需要理解。
- 字符串输入要限制容量，不能用无边界的输入方式；`fgets` 可能保留读到的换行。

### 5.3 选择与循环

`if` 根据条件选择分支；`switch` 从匹配 case 开始，若没有 break 可能继续执行后续分支。`while` 先判断，`do-while` 至少执行一次，`for` 适合有明确初始化、条件和更新的循环。

`break` 离开最近的一层循环或 switch；`continue` 跳过当前循环剩余部分。在 for 中会继续执行更新表达式，再检查条件。推程序时列“本轮 i、条件、变量变化”，不要只凭直觉。

### 5.4 数组与字符串

数组元素连续存储，下标从 0 开始。长度为 n 的数组有效下标为 0～n-1。二维数组按行连续存储，`a[i][j]` 的偏移为 `(i*列数+j)*元素字节数`，这里假设下标从 0 开始。

字符串以 `\0` 结尾。`char s[]="abc";` 有 4 个元素；`strlen(s)` 为 3，`sizeof s` 为 4。字符串字面量不可被修改；需要修改内容时使用可写字符数组。

数组与指针不是同一类型，但数组表达式在许多场合转换为指向首元素的指针。`sizeof` 数组对象与 `sizeof` 指针含义不同；数组形参会调整为指针，函数不能依靠该形参的 sizeof 自动取得实参数组长度。

### 5.5 函数、作用域和递归

C 采用值传递；形参获得实参值的副本。若传的是指针值，可以通过该地址修改外部对象，但指针形参本身仍是副本。

局部变量的作用域与存储期是不同概念；自动局部变量通常随调用创建与结束，静态局部变量跨调用保留值但仍有局部作用域。普通 C 中不能在一个函数体内定义另一个函数；“嵌套调用”是函数之间的调用关系。

递归必须有终止条件，且递归步骤使问题接近终止条件。递归返回时按调用的相反方向恢复执行；手推时同时记录“调用展开”和“返回合并”。

### 5.6 指针与内存

- `&x` 取得 x 的地址；`*p` 访问 p 所指对象；`p+1` 前进一个所指类型元素的距离。
- `int *p[3]` 是含 3 个 int 指针的数组；`int (*p)[3]` 是指向含 3 个 int 的数组的指针。
- `int (*f)(int)` 是指向接收 int、返回 int 的函数的指针；括号不能省。
- `int **p` 是二级指针。需要通过函数修改调用者保存的指针时，可传指针的地址。
- 不返回自动局部变量的地址；不解引用未初始化、空或已经释放的指针；不越界。
- `malloc` 可能失败，所获内存未初始化；使用前检查。释放不再使用的堆内存，避免重复释放。`realloc` 失败时原块仍存在，应先用临时指针接收结果。
- 本课使用标准 C 语法，不用 C++ 引用或 STL 替代大纲要求。

### 5.7 结构体、链表和文件

结构体把多个成员组合为一个对象；`s.x` 访问对象成员，`p->x` 访问指针所指对象的成员。结构体可能存在对齐填充，大小不一定等于成员大小简单相加。共用体成员共享存储空间；枚举定义命名整数常量；typedef 定义类型别名。

链表插入要先保留后继连接，例如在结点 p 后插入 s：`s->next=p->next; p->next=s;`。删除后继时要先保存待删结点、更新连接，再释放。始终说明是否有头结点、是否为循环链表。

文件常用操作：`fopen`、`fclose`、`fgetc/fputc`、`fgets/fputs`、`fscanf/fprintf`、`fread/fwrite`。打开失败返回空指针。读取循环应以读操作返回结果为依据，不用 `while(!feof(fp))` 预判“下一次必定能读”。`fgetc` 的结果先用 int 保存，以区分普通字符值与 EOF。

### 5.8 线性表、栈和队列

顺序表按下标访问为 O(1)，中间插入删除通常要移动元素，最坏 O(n)。单链表不能常数时间随机访问；在已知合适前驱的前提下，改链接本身可为 O(1)，寻找位置的成本另算。

栈后进先出，适用于括号匹配、表达式处理、递归模拟。队列先进先出，适用于层序遍历和任务排队。

循环队列采用“空出一个位置”约定、容量 M 时：空为 `front==rear`；满为 `(rear+1)%M==front`；元素数为 `(rear-front+M)%M`；最多存 M-1 个元素。若题目采用计数器或标志位，要按题设改判定规则。

### 5.9 串与压缩存储

串的元素是字符，空串长度为 0，不能与包含空格的串混淆。朴素模式匹配最坏 O(nm)；KMP 利用已匹配前后缀避免主串指针反复回退，预处理和匹配合计 O(n+m)。

KMP 的 next 数组有不同下标与哨兵约定，解题前必须声明。本课程可先用零下标前缀函数 π：π[i] 表示模式串前缀 `P[0..i]` 的最长相等真前后缀长度，再说明与教材 next 形式的对应，不能混用。

对称矩阵可只存一个三角区；若存下三角含主对角线、按行且从零计下标，i≥j 时压缩下标为 `i(i+1)/2+j`。i<j 时先利用对称性交换。三角矩阵非存储区可能是同一个常量，与对称矩阵不同。稀疏矩阵可用三元组记录行、列和值。

### 5.10 树、二叉树和哈夫曼

二叉树每个结点最多两个孩子，左右有区别，不等于“任意度为 2 的树”。若根为第 1 层，第 i 层最多 2^(i-1) 个结点；高度 h 的二叉树最多 2^h-1 个结点。非空二叉树有 n0=n2+1，n0 是叶结点数，n2 是度为 2 的结点数。

前序：根左右；中序：左根右；后序：左右根；层序使用队列。结点标识互不相同时，前序+中序或后序+中序可唯一确定二叉树；前序+后序一般不行。

线索化利用原本为空的指针记录某种遍历顺序的前驱/后继，并用标志区分孩子指针和线索。树与森林转为二叉树常用“左孩子、右兄弟”表示，不能把兄弟误当成原树的孩子。

哈夫曼算法反复合并权值最小的两棵树。WPL 为所有叶子“权值×从根到该叶子的边数”之和。权值相同可能有多个同样最优的树，编码未必唯一；左右赋 0/1 的约定也会影响具体码字。

### 5.11 图算法

邻接矩阵通常占 O(V²) 空间，邻接表通常占 O(V+E) 空间。DFS 通常用递归/栈，BFS 用队列；非连通图要从未访问顶点继续启动遍历。给出顶点和邻接点访问顺序，才能确定具体遍历序列。

| 算法 | 解决的问题 | 条件与易错处 |
|---|---|---|
| Prim / Kruskal | 最小生成树 | 通常讨论连通无向带权图；不连通则得到生成森林 |
| Dijkstra | 单源最短路径 | 标准算法要求边权非负；不是最小生成树算法 |
| Floyd | 所有顶点对最短路径 | 可处理负边，但存在相关负环时不能得到有限最短路；典型 O(V³) |
| 拓扑排序 | 有向无环图的先后约束 | 序列可能不唯一；无法输出全部顶点说明有环 |
| 关键路径 | AOE 网的工期和关键活动 | 在相应有向无环活动网络上分析；关键路径可能不止一条 |

关键路径按拓扑序求事件最早时刻 ve，逆序求最迟时刻 vl。活动 u→v、持续时间 w，其最早开始 e=ve[u]，最迟开始 l=vl[v]-w；e=l 为关键活动。多源或多汇时先明确工程起止约定。

### 5.12 查找

顺序查找不要求有序；折半查找要求有序且适合随机访问。折半查找不仅要背 O(log n)，还要会更新区间、判断失败以及计算题目指定的比较次数。

索引顺序查找把表分块，常见约定是块内无序、块间有序，通过索引定位块再块内查找。ASL 是查找长度的概率加权平均，成功和失败分别计算，不能默认所有输入等概率。

BST 左子树关键字小于根、右子树大于根（重复值策略另约定）；删除有两个孩子的结点时通常用前驱或后继替代。退化成链时查找可为 O(n)。AVL 通过旋转维持平衡因子绝对值不超过 1，需掌握 LL/RR/LR/RL。

常见 m 阶 B 树约定：结点最多 m 个孩子、m-1 个关键字；非根内部结点至少 ceil(m/2) 个孩子；根有例外；所有叶子在同一层。B+树的记录或记录指针集中在叶层，叶层通常相连，适合范围查询。具体阶数、关键字数和叶层定义以题设/教材约定为准。

哈希查找需要哈希函数和冲突处理。开放定址与链地址法是两类常见方法；装填因子与冲突影响性能。平均接近 O(1) 需要合适分布和负载，最坏仍可 O(n)。开放定址删除不能简单抹为空位而破坏后续探测链。

### 5.13 排序比较速查

下表以常见数组实现为前提；稳定表示相同关键字记录的原先顺序保留。n 为记录数，d 为位数，r 为每位的取值范围。

| 算法 | 平均时间 | 最坏时间 | 典型辅助空间 | 稳定性 |
|---|---|---|---|---|
| 直接插入 | O(n²) | O(n²) | O(1) | 稳定 |
| 折半插入 | O(n²) | O(n²) | O(1) | 稳定实现可行，取决于相等元素的插入位置 |
| 希尔 | 依赖增量序列 | 依赖增量序列 | O(1) | 不稳定 |
| 直接选择 | O(n²) | O(n²) | O(1) | 通常不稳定 |
| 堆排序 | O(n log n) | O(n log n) | O(1) | 不稳定 |
| 冒泡 | O(n²) | O(n²) | O(1) | 稳定 |
| 快速排序 | O(n log n) | O(n²) | 典型递归平均 O(log n)、最坏 O(n) | 不稳定 |
| 归并排序 | O(n log n) | O(n log n) | 常见数组实现 O(n) | 稳定 |
| 基数排序 | O(d(n+r)) | O(d(n+r)) | 常见实现 O(n+r) | 各趟分配收集稳定时稳定 |

折半插入减少比较次数，不消除元素移动。带提前结束标志的冒泡、有序输入上的直接插入最好可为 O(n)。建堆可在 O(n) 完成，不必按 n 次完整插入理解。快速排序的划分方式有多种，题目指定方法时逐趟结果必须遵循该方法。

外部排序用于数据不能全部放入内存的情况：生成初始有序段，再多路归并。需要理解内外存 I/O、归并趟数、缓冲区；置换选择和败者树可作为“外部排序方法”的配套讲解。若有 R 个初始有序段，每趟最多 k 路、k≥2，归并趟数通常为 ceil(log_k R)，初始段生成另计。

### B. 第一课讲解（约 10 分钟）

#### 一个核心：先看参与运算的类型，再看接收结果的类型

```c
int a = 5, b = 2;
double x = a / b;
double y = (double)a / b;
```

第一步看 `a/b`：两个操作数都是 int，执行整数除法，得到 2。第二步赋给 double，变为 2.0。因此 x 为 2.0。

`(double)a/b` 在除法前把 a 转为 double，随后按浮点方式运算，得到 2.5。因此 y 为 2.5。

注意 `(double)(a/b)` 的括号顺序不同，它是在整数除法已经完成后才转换，结果仍为 2.0。

#### 一个方法：逐轮列状态

```c
int sum = 0;
for (int i = 1; i <= 4; i++) {
    if (i == 2) continue;
    sum += i;
}
```

| i | 是否跳过累加 | 本轮结束后的 sum |
|---:|---|---:|
| 1 | 否 | 1 |
| 2 | 是 | 1 |
| 3 | 否 | 4 |
| 4 | 否 | 8 |

`continue` 不等于结束循环，它只跳过当前轮剩余部分。若改为 `break`，i=2 时整个循环就结束，sum 只剩 1。

#### 一个复杂度例子

遍历一个含 n 个元素的数组求和，每个元素处理一次，时间复杂度 O(n)。若只用一个累加变量，辅助空间 O(1)。输入数组本身的大小与“额外使用的辅助空间”应区分。

### P004 函数的值传递与指针参数

C 的函数参数始终按值传递：传入普通整数时，形参获得整数值的副本；传入地址时，指针形参获得地址值的副本。通过这个地址可以访问并修改调用者的对象，但修改指针形参自身并不自动改变调用者的指针变量。

- `void f(int x)` 中给 x 赋值，通常只修改局部形参。
- `void g(int *p)` 中给 `*p` 赋值，修改的是该地址所指对象。
- 调用 `g(&a)` 时，`&a` 作为地址实参传入，函数中的 p 指向调用者的 a。

### P005 用指针参数实现交换

### P007 数组与指针移动


### P008 后缀自增与解引用

后缀自增表达式的结果是被自增对象的旧值，同时使该对象增加 1。后缀 ++ 的优先级高于一元解引用 *。

| 表达式 | 结合方式 | 表达式取到什么 | 副作用 |
|---|---|---|---|
| `*p++` | `*(p++)` | 旧 p 所指的元素值 | p 前进一个元素，数组元素值不变 |
| `(*p)++` | 对所指元素后缀自增 | 所指元素的旧值 | 元素值加 1，p 指向不变 |

例如 `int x=*p++;` 完整语句执行后，x 保存旧 p 所指元素的值，而 p 已前进。不要把“表达式取旧值”描述为在整个程序中具有固定求值顺序；这里只跟踪各独立完整语句结束后的状态。教学题不把对同一对象的未排序读写塞入同一个表达式。

### S001 结构体与结构体指针

结构体把同一对象的多个属性组合成一个自定义类型。用机器人状态举例：电量是int，速度是double。

```c
struct RobotState {
    int battery;
    double speed;
};
```

这是类型定义，结尾需要分号。`struct RobotState r={80,0.5};` 创建变量r，并按成员声明顺序初始化battery和speed。`struct RobotState *p=&r;` 创建指向该结构体对象的指针p。

| 对象/表达式 | 用法 |
|---|---|
| r 是结构体变量 | `r.battery`、`r.speed` |
| p 是结构体指针 | `p->battery`、`p->speed` |
| 先解引用再访问 | `(*p).battery` 等价于 `p->battery` |

运算符 -> 由相邻的减号和大于号组成。`(*p).battery` 中括号有作用：先通过p取得结构体对象，再用点访问成员。不要将它写成 `*p.battery`。通过p修改成员会改变实际对象r的相应成员。

```c

    int battery;
    double speed;
};

int main(void) {
    struct RobotState r = {80, 0.5};
    struct RobotState *p = &r;
    p->battery -= 10;
    p->speed = 1.0;
    return 0;
}
```

执行后 r.battery、r.speed、p->battery 分别是多少？p 指向谁？先识别成员访问对象，再看赋值操作。后续再学习结构体传值、指针传参、结构体数组及链表结点。
