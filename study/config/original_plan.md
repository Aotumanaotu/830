## 2. 训练与记录规则

### 一次标准课：约 60～90 分钟

| 环节 | 时间参考 | 产出 |
|---|---:|---|
| 复习到期错题 | 10 分钟 | 不看答案重做 |
| 新知识与例题 | 20～30 分钟 | 能用自己的话解释 |
| 独立练习 | 20～30 分钟 | 答案、思路、用时 |
| 批改与总结 | 10～20 分钟 | 错因与下一次复习 |

忙碌日保底：10 分钟复习 + 10 分钟新知识 + 10 分钟两道小题。遗漏课程顺延，并每周重排，不靠一次性补大量作业弥补。

### 掌握度与证据

- 未测：没有独立作答证据；不能推断不会。
- 学习中：接触过讲解，尚未通过独立练习。
- 待巩固：同类基础题可做，但变式、解释或边界情况不稳。
- 初步掌握：独立完成覆盖主要目标的小测，约 80% 及以上，能解释关键步骤。
- 稳定掌握：隔日和隔周的变式复测均通过，关键概念无明显错误。

以上是教学调整标准，不是学校评分标准。程序题即使偶然输出正确，也需要检查算法、边界、指针安全和复杂度。看完讲义不等于通过测评。

### 间隔复习

新知识首次练习后，建议安排第 1、3、7、14 天复测；以实际完成日计算。答错的知识点回到短间隔，答对且解释清楚的适当延长。临考不足 14 天时压缩间隔。尚未作答的题不预记正确率、不生成虚假复习完成记录。

### 错因标签

概念混淆 / 语法规则 / 边界遗漏 / 指针与内存 / 推演步骤 / 复杂度 / 粗心 / 时间不足。

每道错题保存：原题、用户原答案、评分依据、正确思路、错误原因、一个变式、下次复习日、复测结果。用户未报告学习时长时记“未报告”，不根据对话时间估算。

## 3. 暂定排期

本排期仅分配 830 专业课时间。结合用户时间上限与数学需要，先安排工作日每天约 90 分钟、周六周日各约 3 小时，合计约 13.5 小时/周。周末拆成两个 90 分钟时段；这是可调整的专业课预算，不是用户已承诺或已完成的时长。优先级是教学顺序，不是预测出题概率。

| 日期 | 核心内容 | 检验方式 |
|---|---|---|
| 10/08—10/11 | 表达式、循环、数组和函数快速诊断；开始指针 | 短题判断规则理解，避免重复学习已会内容 |
| 10/12—10/18 | 指针专项：地址、解引用、数组、字符串、传参、二级指针、动态内存；结构体 | 画对象和指向关系；读写小程序 |
| 10/19—10/25 | 结构体链表、递归、复杂指针、共用体枚举、文件；线性表、栈队列 | 手写增删查；跟踪递归和队列 |
| 10/26—11/01 | 串与 KMP、压缩矩阵、二叉树基础与遍历 | 匹配推演、地址计算、树遍历 |
| 11/02—11/08 | 线索二叉树、树森林、哈夫曼；图存储与遍历 | 结构转换、WPL、DFS/BFS |
| 11/09—11/15 | MST、最短路、拓扑和关键路径；查找基础与 BST/AVL | 手推算法；讲清限制条件；旋转 |
| 11/16—11/22 | B/B+树、哈希；内部排序与外部排序，第一轮覆盖 | 查找效率、逐趟排序与性能比较 |
| 11/23—12/06 | 第二轮专项训练，交叉复习 C 和数据结构 | 薄弱点优先；综合编程与过程题 |
| 12/07—12/16 | 限时综合训练、错题复测 | 根据正确率和耗时分配训练 |
| 12/17—12/18 | 易错点、公式、熟悉代码回顾 | 轻量复习 |

树、图、平衡查找等每单元先做小诊断，不能因用户说“简单的还行”就标记为掌握。第一轮是覆盖目标，达标仍以独立作答为准；如果进度不足，每周调整专题时数，不直接删除大纲内容。
