### 5.5 函数、作用域和递归

C 采用值传递；形参获得实参值的副本。若传的是指针值，可以通过该地址修改外部对象，但指针形参本身仍是副本。

局部变量的作用域与存储期是不同概念；自动局部变量通常随调用创建与结束，静态局部变量跨调用保留值但仍有局部作用域。普通 C 中不能在一个函数体内定义另一个函数；“嵌套调用”是函数之间的调用关系。

递归必须有终止条件，且递归步骤使问题接近终止条件。递归返回时按调用的相反方向恢复执行；手推时同时记录“调用展开”和“返回合并”。


### P009 数组作为函数参数

函数参数中的 `int a[]` 会调整为 `int *a`：函数接收首元素地址的副本，可以通过下标访问并修改调用者的数组元素。通常还需要单独传入处理数量 n，函数不能从该指针形参自动得知整个数组长度。

| 调用者对象 | 传给 int 指针形参的常见表达式 |
|---|---|
| 单个 int 变量 x | `&x` |
| int 数组 a | `a` 或 `&a[0]` |

调用处写数组名 a 时，它在此场景转换为首元素地址；不把前面单变量取地址规则机械套为 `&a`，后者对整个数组取地址，类型不同。数组形参 a 本身仍是独立指针变量，修改形参指向和修改数组元素应区分。
