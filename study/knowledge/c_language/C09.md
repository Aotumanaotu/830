### 5.6 指针与内存

- `&x` 取得 x 的地址；`*p` 访问 p 所指对象；`p+1` 前进一个所指类型元素的距离。
- `int *p[3]` 是含 3 个 int 指针的数组；`int (*p)[3]` 是指向含 3 个 int 的数组的指针。
- `int (*f)(int)` 是指向接收 int、返回 int 的函数的指针；括号不能省。
- `int **p` 是二级指针。需要通过函数修改调用者保存的指针时，可传指针的地址。
- 不返回自动局部变量的地址；不解引用未初始化、空或已经释放的指针；不越界。
- `malloc` 可能失败，所获内存未初始化；使用前检查。释放不再使用的堆内存，避免重复释放。`realloc` 失败时原块仍存在，应先用临时指针接收结果。
- 本课使用标准 C 语法，不用 C++ 引用或 STL 替代大纲要求。


### P001 指针入门：地址、指针与所指对象

```c
int a = 10;
int *p = &a;
*p = 20;
```

- a 是一个保存整数的变量。
- `&a` 是 a 的地址。
- p 是指针变量，保存 a 的地址；声明 `int *p` 表明它用于指向 int 对象。
- 表达式 `*p` 访问 p 所指的整数对象，这里就是 a。
- 因此 `*p=20` 修改的是 a，最后 a 和表达式 `*p` 的值都是 20；p 仍保存原来的地址。
- 声明中的星号用于声明指针类型，表达式中的星号用于解引用，不能统一解释为乘法或取地址。


### P002 改变指向与修改所指对象

- `p=&b`：改变指针变量 p 保存的地址，使 p 指向 b；这一步不修改 a 或 b 的整数值。
- `*p=30`：保持 p 的指向，修改 p 当前所指对象的整数值。
- 每遇到 `*p`，先确认这一行执行时 p 指向哪个对象。


### P003 两个指针之间的赋值

`int *q=p;` 把 p 当时保存的地址复制给 q。两个指针变量各自保存地址；之后改变 p 的指向不会自动改变 q。这个道理与 `int b=a` 复制当时的整数值相通。


### P004 函数的值传递与指针参数

C 的函数参数始终按值传递：传入普通整数时，形参获得整数值的副本；传入地址时，指针形参获得地址值的副本。通过这个地址可以访问并修改调用者的对象，但修改指针形参自身并不自动改变调用者的指针变量。

- `void f(int x)` 中给 x 赋值，通常只修改局部形参。
- `void g(int *p)` 中给 `*p` 赋值，修改的是该地址所指对象。
- 调用 `g(&a)` 时，`&a` 作为地址实参传入，函数中的 p 指向调用者的 a。
- 不把上述现象称为 C++ 意义的引用传递，C 中复制的是指针值。


### P005 用指针参数实现交换

交换需要保存旧值：先保存第一个数，再把第二个数写入第一个位置，最后把保存的旧值写入第二个位置。否则覆盖后会丢失原数值。函数使用指针形参时，应通过解引用读写调用者的整数，调用时传入对应变量地址。


### P006 修改指针形参自身

指针形参也是独立变量，调用时复制的是地址值。`p=q` 修改函数局部指针 p 保存的地址，不会自动改变调用者的指针变量；随后 `*p=50` 修改 p 此时所指的对象。要分别跟踪“调用者的指针”和“函数中的指针形参”。


### P007 数组与指针移动

```c
int a[3] = {10, 20, 30};
int *p = a;
```

在 `int *p=a` 这个初始化表达式中，数组 a 转换为首元素地址，等价于用 `&a[0]` 初始化 p。此时 `*p` 访问 a[0]，`*(p+1)` 访问 a[1]，`*(p+2)` 访问 a[2]。数组下标从 0 开始。

指针加 1 前进一个所指类型元素；int 指针前进一个 int 元素，其字节距离为 sizeof(int)，不默认某个平台固定类型大小。`p+1` 仅产生新地址值，不修改 p；`p=p+1` 或 `p++` 才改变 p 保存的地址。

访问时必须在有效数组元素内：可以形成指向数组末尾后一位置的指针，但不能对它解引用。数组与指针不是相同类型，这里只针对上述初始化场景解释转换。


### P008 后缀自增与解引用

后缀自增表达式的结果是被自增对象的旧值，同时使该对象增加 1。后缀 ++ 的优先级高于一元解引用 *。

| 表达式 | 结合方式 | 表达式取到什么 | 副作用 |
|---|---|---|---|
| `*p++` | `*(p++)` | 旧 p 所指的元素值 | p 前进一个元素，数组元素值不变 |
| `(*p)++` | 对所指元素后缀自增 | 所指元素的旧值 | 元素值加 1，p 指向不变 |

例如 `int x=*p++;` 完整语句执行后，x 保存旧 p 所指元素的值，而 p 已前进。不要把“表达式取旧值”描述为在整个程序中具有固定求值顺序；这里只跟踪各独立完整语句结束后的状态。教学题不把对同一对象的未排序读写塞入同一个表达式。
