### 5.13 排序比较速查

下表以常见数组实现为前提；稳定表示相同关键字记录的原先顺序保留。n 为记录数，d 为位数，r 为每位的取值范围。

| 算法 | 平均时间 | 最坏时间 | 典型辅助空间 | 稳定性 |
|---|---|---|---|---|
| 直接插入 | O(n²) | O(n²) | O(1) | 稳定 |
| 折半插入 | O(n²) | O(n²) | O(1) | 稳定实现可行，取决于相等元素的插入位置 |
| 希尔 | 依赖增量序列 | 依赖增量序列 | O(1) | 不稳定 |
| 直接选择 | O(n²) | O(n²) | O(1) | 通常不稳定 |
| 堆排序 | O(n log n) | O(n log n) | O(1) | 不稳定 |
| 冒泡 | O(n²) | O(n²) | O(1) | 稳定 |
| 快速排序 | O(n log n) | O(n²) | 典型递归平均 O(log n)、最坏 O(n) | 不稳定 |
| 归并排序 | O(n log n) | O(n log n) | 常见数组实现 O(n) | 稳定 |
| 基数排序 | O(d(n+r)) | O(d(n+r)) | 常见实现 O(n+r) | 各趟分配收集稳定时稳定 |

折半插入减少比较次数，不消除元素移动。带提前结束标志的冒泡、有序输入上的直接插入最好可为 O(n)。建堆可在 O(n) 完成，不必按 n 次完整插入理解。快速排序的划分方式有多种，题目指定方法时逐趟结果必须遵循该方法。

外部排序用于数据不能全部放入内存的情况：生成初始有序段，再多路归并。需要理解内外存 I/O、归并趟数、缓冲区；置换选择和败者树可作为“外部排序方法”的配套讲解。若有 R 个初始有序段，每趟最多 k 路、k≥2，归并趟数通常为 ceil(log_k R)，初始段生成另计。
