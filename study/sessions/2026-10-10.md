无头结点、以NULL结束的单链表。headp保证指向main中有效首指针变量，*headp可为NULL。函数摘下首结点，用二级指针更新main的head，同时返回被摘下结点地址；空链表返回NULL。本题只改连接，不释放对象。补全：

struct Node *pop_front(struct Node **headp) {
    if (*headp == NULL) {
        return NULL;
    }
    struct Node *q = *headp;
    /* ① 将main的head改为q的后继 */
    q->next = NULL;
    return /* ② 被摘下结点地址 */;
}

main中初始a→b→c→NULL，各结点为有效局部对象：

struct Node *head = &a;
struct Node *removed = pop_front(/* ③ */);

1. ①完整语句，带分号。
2. ②返回表达式，不必重复return和分号。
3. ③调用时的实参表达式。

二级指针负责更新head，返回值负责交回摘下结点地址；本函数返回类型为struct Node *，因此可以返回结点地址。
