## 4. 大纲全覆盖清单

C03、C08、C09 已开始局部练习，相关单元仍为“学习中”；C10 开始结构体入门，尚未收到作答。其余单元尚未完成测评。C09、C10 为用户自述薄弱。“已准备提要”只描述材料状态。

| 编号 | 大纲单元 | 必须会的内容 | 达标任务 |
|---|---|---|---|
| C01 | 概述 | C 程序特点、算法性能度量 | 分清编译错误、运行错误、逻辑错误；分析数量级 |
| C02 | 算法 | 算法概念、表示、结构化设计 | 用自然语言、流程或伪代码描述算法 |
| C03 | 数据类型、运算符与表达式 | 常量变量、整数实数字符、初始化、类型转换、算术、赋值、逗号 | 正确推导表达式类型与值 |
| C04 | 顺序结构 | 输入输出与顺序程序 | 写完整输入处理输出程序 |
| C05 | 选择结构 | 关系逻辑、if、switch | 分支判定、短路、case 穿透 |
| C06 | 循环结构 | 三种循环、嵌套、break/continue | 跟踪边界与执行次数 |
| C07 | 数组 | 一维、二维、字符数组 | 遍历、矩阵处理、字符串结束符 |
| C08 | 函数 | 定义调用、嵌套调用、递归、数组参数、作用域、存储期 | 手推递归；说明形参和实参关系 |
| C09 | 指针 | 变量/数组/字符串/函数指针、指针返回、指针数组、二级指针、动态分配 | 读懂声明；正确修改数据与指针 |
| C10 | 结构体及应用 | 结构体、数组、指针、链表、共用体、枚举、typedef | 链表增删查；区分对象布局与类型别名 |
| C11 | 文件 | 文件概念、FILE 指针、打开关闭、读写 | 判断返回值、区分文本和二进制模式 |
| D01 | 绪论 | 数据结构术语、算法描述与分析 | 分清逻辑结构和存储结构 |
| D02 | 线性表 | 定义、基本运算、顺序存储、链式存储 | 插入删除；分析查找和移动成本 |
| D03 | 栈和队列 | 定义表示实现、表达式求值、递归及应用 | 栈序列、循环队列、应用选型 |
| D04 | 串 | 定义表示实现、模式匹配 | 手推朴素匹配和 KMP |
| D05 | 数组 | 定义运算、顺序存储、压缩矩阵 | 地址计算；对称/三角/稀疏矩阵表示 |
| D06 | 树和二叉树 | 概念性质存储、遍历、线索、树森林转换、哈夫曼 | 还原树、线索关系、编码与 WPL |
| D07 | 图 | 概念、邻接矩阵/表、遍历、MST、最短路、拓扑、关键路径 | 建图、手推、说明限制条件 |
| D08 | 查找 | 顺序、折半、索引、BST、AVL、B/B+树、哈希、效率 | ASL、旋转、分裂、冲突处理 |
| D09 | 排序 | 插入/折半插入/希尔、选择/堆、冒泡/快排、归并、基数、外排 | 手推每趟；比较时间、空间、稳定性 |

### 前置知识补充表

| 前置知识 | 用在哪里 | 补到什么程度 |
|---|---|---|
| 对数与等差/等比求和 | 复杂度、树高 | 会判断倍增次数与累加项数 |
| 余数运算 | 循环队列、哈希 | 理解非负下标循环回绕 |
| 地址、字节、连续存储 | 数组和指针 | 会区分地址、对象和值；不预设所有平台类型大小 |
| 递归栈与数学归纳思路 | 链表、树、排序 | 找终止条件、缩小规模、推导返回结果 |
| 图示与状态跟踪 | 指针、图算法、排序 | 能画箭头和逐步更新状态 |
| 简单证明与边界检查 | 程序设计题 | 检查空输入、单元素、重复值、首尾位置 |

这些内容按需要嵌入课程，不另开大规模超纲学习路线。
